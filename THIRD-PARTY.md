# Third-party components

WehniX Launcher integrates third-party libraries and runtime components. Their licenses govern those components independently of the proprietary launcher license.

Bundled components may include Wine, .NET, SteamKit, DepotDownloader, compression libraries and graphics/runtime dependencies. Each approved binary must include the applicable complete notices, license texts and any required corresponding source or valid source offer for the exact distributed versions.

The current development engine packages are marked for local use. Corresponding-source obligations and redistribution permissions, including Apple Game Porting Toolkit components, remain under review. Public binary release is pending completion of those obligations and permissions. This repository currently provides release documentation only.
